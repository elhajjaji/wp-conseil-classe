## Visuels : GitHub vs WordPress.org

- **Documentation GitHub (`docs/`)** : images optionnelles dans `docs/images/` pour illustrer le Markdown.
- **Fiche officielle sur WordPress.org** : bannières, icônes et `screenshot-1.png`, etc. déposés dans le dossier SVN **`assets/`**, avec textes dans **`readme.txt`** — voir le guide dédié **[Publication sur WordPress.org](publication-wordpress-org.md)** et le dossier **`wordpress-org/assets/`** dans le dépôt.
