# Exemples d'import

Ces fichiers sont basés sur les visuels fournis pour le collège Paul Langevin.

Ordre conseillé d'import :

1. Importer `01-parametres.csv` depuis l'écran Paramètres.
2. Créer ou activer manuellement l'année scolaire `2025-2026`.
3. Activer manuellement le trimestre `T2`.
4. Importer `02-classes-2025-2026.csv` depuis l'écran Classes.
5. Importer `03-conseils-t2-2025-2026.csv` depuis l'écran Conseils.
6. Importer `04-parents.csv` depuis l'écran Parents.
7. Importer `05-admins-conseil.csv` si besoin pour l'équipe de gestion.

Notes :

- Le planning fourni ici est prévu pour le trimestre actif `T2` de l'année `2025-2026`.
- Le plugin ne propose pas d'import CSV pour les années scolaires, les trimestres ou les inscriptions aux conseils.
- Les séparateurs utilisés dans ces fichiers sont des points-virgules `;`, compatibles avec l'import du plugin.
